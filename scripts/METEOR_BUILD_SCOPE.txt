Golden packaging rule:
  Never mix portapack-mayhem-firmware.bin from build A with .ppma from build B.
  Prefer portapack-mayhem_OCI.ppfw.tar from one build for Flash Utility (FIRMWARE/ on SD).

Canonical Docker commands: see scripts/stable-meteor-docker.ps1 (-UseWsl if Windows bind mounts fail), scripts/stable-meteor-docker.sh. Logs and copies: share-out/logs/, share-out/artifacts/.

SPI pack (H4M / W25Q80): use -DFLASH_MB_SIZE=2 -DFLASH_MB_LIMIT_SIZE=1 (1048576-byte .bin). Do NOT use LIMIT=2 on 1 MiB hardware. See scripts/H4M_METEOR_BUILD.txt.

Host: Docker Desktop needs enough RAM for parallel arm-none-eabi-g++; if builds die with "Cannot allocate memory", use MAYHEM_MAKE_JOBS=1 or give the VM more memory.
