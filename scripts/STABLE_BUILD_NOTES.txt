Stable Mayhem + Meteor — quick reference (do not edit the plan in .cursor/plans/)

H4M / 1 MiB SPI (W25Q80-class):
  ./scripts/stable-meteor-docker-1mb.sh
  (SIZE=2 LIMIT=1 — matches official 1 MiB Mayhem; see scripts/BOOT_FAILURE_H4M.md)
  Output .bin must be 1048576 bytes.

Docker one-liner (after `docker build -f dockerfile-nogit -t portapack-dev .`):
  docker run --rm -v "${PWD}:/havoc" portapack-dev \
    -DFLASH_MB_SIZE=2 -DFLASH_MB_LIMIT_SIZE=1 make -j1

Use MAYHEM_MAKE_JOBS=2 only if Docker has enough RAM (otherwise OOM / bind-mount I/O errors).

Every full Docker run writes a log under share-out/logs/ and copies the flash bundle to share-out/artifacts/ (see share-out/README.txt).
Default parallelism is -j1 inside Docker (OOM-safe); set MAYHEM_MAKE_JOBS if your machine has headroom.

Resume after OOM: scripts/docker-resume-share-out.sh (keeps build/, logs to share-out/logs/).

Artifacts (same build tree — never mix):
  build/firmware/portapack-mayhem-firmware.bin
  build/firmware/portapack-mayhem_OCI.ppfw.tar
  build/firmware/application/meteor_lrpt_rx.ppma

Two clean builds — compare share-out/artifacts/SHA256SUMS.txt copies between runs:
  ./scripts/stability-compare-builds.sh share-out/artifacts/SHA256SUMS.txt share-out/artifacts/SHA256SUMS.prev.txt

SPI gate: ./scripts/spi-gate-check.sh (or grep logs for make_spi_image RuntimeError).

Device checklist: SD FIRMWARE\ with ppfw.tar; rollback = DFU + official 1 MiB bin (flashing/README.txt).
